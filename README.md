# Portfolio Personal - Josep Mª Mateu

Bienvenido a mi portfolio personal v2. Este proyecto es una aplicación web diseñada para mostrar mi perfil profesional, habilidades técnicas y una selección de mis proyectos más relevantes como Desarrollador de Software.

## 📋 Descripción

Este portfolio destaca por un diseño moderno, limpio y totalmente responsivo ("Mobile First"), garantizando una excelente experiencia de usuario en cualquier dispositivo. En él detallo mi trayectoria desde el sector industrial hacia el desarrollo de software, mis competencias técnicas y mis trabajos prácticos.

## 🚀 Stack Tecnológico del Portfolio

El sitio ha sido construido utilizando tecnologías web estándar sin dependencias pesadas, asegurando alto rendimiento y facilidad de mantenimiento:

*   **Estructura:** HTML5 Semántico
*   **Estilos:** CSS3 Moderno (Variables CSS, Flexbox, Grid, Animaciones y Transiciones)
*   **Lógica:** JavaScript (Vanilla JS ES6+) para la interactividad y navegación
*   **Recursos:** 
    *   [Ionicons](https://ionic.io/ionicons) para la iconografía
    *   [Google Fonts](https://fonts.google.com/) (Familia Poppins)

## 📂 Secciones Principales

El contenido está organizado en pestañas de navegación fluida:

1.  **Sobre mí:** 
    *   Introducción sobre mi perfil híbrido (Mecatrónica/Robótica + Desarrollo de Software).
    *   Servicios: Diseño Web, Desarrollo, Apps Móviles e IA & Automatización.
    *   **Stack Tecnológico:** Visualización de mis competencias en Java, Python, Web (HTML/CSS/JS), Móvil (Kotlin/Dart/Flutter) y Backend (MySQL/Firebase).
2.  **CV (Currículum):** 
    *   Timeline vertical detallando mi formación académica (DAM, Robótica, Mecatrónica).
    *   Historial de experiencia laboral (Mantenimiento de sistemas, Técnico SAT, etc.), destacando habilidades transferibles como resolución de problemas y trabajo en equipo.
3.  **Portfolio:** 
    *   Galería de proyectos con filtrado por categorías: "Todos", "App Móviles", "Escritorio & IA", "Redes & Sistemas".
4.  **Contacto:** 
    *   Información de contacto directa y enlaces a redes profesionales.

## 🌟 Proyectos Destacados

Entre los proyectos exhibidos se encuentran:

*   **Gestor Financiero:** Aplicación móvil (Flutter) para el control personal de gastos e ingresos.
*   **Asistente Virtual:** Software de automatización y control por comandos de voz.
*   **Transferencia de Archivos WiFi:** Solución para enviar archivos entre equipos en red local vía IP.

## 🛠️ Cómo ejecutar el proyecto

Al ser un sitio estático, es muy fácil de visualizar localmente:

1.  **Clonar o descargar** este repositorio.
2.  Navegar a la carpeta raíz del proyecto.
3.  Hacer doble clic en el archivo `index.html` para abrirlo en tu navegador favorito.
    *   *Opcional:* Para una mejor experiencia de desarrollo, puedes usar una extensión como "Live Server" en VS Code.
